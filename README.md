Symmetric Venn Diagrams


Feature request, if we can do it without much UI clutter:
A checkbox for each of the n curves, initially all unchecked. Whatever subset of them you check, the corresponding region in the Venn diagram is highlighted.
This would mainly be for pedagogical purposes as an interactive way to appreciate what this is all about.

If we wanted to be super fancy we could have a button to rotate the Venn diagram, including the highlighted region, by tau/n and have the checkboxes change to indicate which region is now highlighted after rotation.
